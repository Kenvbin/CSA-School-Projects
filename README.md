# AP Computer Science A / 2022-2023

This repo is a collection of Java programming assignments from when I was taking AP Computer Science A

## Chapter 2

- **[2-1](assignments/Ch2/2-1/)** - A program that just prints out information in the console
- **[2-2](assignments/Ch2/2-2/)** - Prints out ASCII art
- **[2-4](assignments/Ch2/2-4/)** - Takes an input of years from the user and converts it into minutes
- **[2-5](assignments/Ch2/2-5/)** - Calculates an object's momentum based on its mass and velocity
## Chapter 3

- **[3-1](assignments/Ch3/3-1/)** - Calculates the surface area of a cube with a user's inputted length
- **[3-2](assignments/Ch3/3-2/)** - Calculates a sphere's diameter, circumference, surface area, and volume from its radius
- **[3-3](assignments/Ch3/3-3/)** - Calculates an object's momentum and kinetic energy using its mass and velocity
- **[3-4](assignments/Ch3/3-4/)** - Calculates weekly earnings based on hourly wage, regular hours, and overtime
## Chapter 4
- **[4-0](assignments/Ch4/4-0/)** - Simulates 10 coin flips and counts the number of heads and tails
- **[4-00](assignments/Ch4/4-00/)** - A rock paper scissors game against a computer player
- **[4-1](assignments/Ch4/4-1/)** - Calculates the quotient and remainder of two integers
- **[4-2](assignments/Ch4/4-2/)** - Determines whether three side lengths form a right triangle using the Pythagorean theorem
- **[4-3](assignments/Ch4/4-3/)** - Calculates the cost of a telephone call based on its duration and a pricing structure
- **[4-5](assignments/Ch4/4-5/)** - Approximates the value of pi by using a series
- **[4-7](assignments/Ch4/4-7/)** - A program that calculates powers of two until the user chooses to exit
## Chapter 6
- **[6-0](assignments/Ch6/6-0/)** - Introduction of classes and methods by using a Penguin object
- **[6-00](assignments/Ch6/6-00/)** - Demonstration of object construction and initialization through a class representing a person's age and weight
- **[6-1](assignments/Ch6/6-1/)** - Implements a Student class that stores test scores and calculates things like averages and minimum scores
- **[6-5](assignments/Ch6/6-5/)** - Implements a bank account system that allows users to deposit and withdraw money while tracking their balance
## Chapter 7
- **[7-1](assignments/Ch7/7-1/)** - A number guessing game where the player has to try and guess a randomly generates number while getting feedback after every guess
- **[7-2](assignments/Ch7/7-2/)** - Reverses the number guessing game by having the computer guess a number the user chose while narrowing its range
- **[7-5](assignments/Ch7/7-5/)** - Demonstration of the Euclidean algorithm
- **[7-6](assignments/Ch7/7-6/)** - Simulates the Lucky Sevens dice game to estimate the average number of rolls before a player's balance reaches zero
- **[7-8](assignments/Ch7/7-8/)** - Calculates the word count, average word length, and total character count from a user provided sentence
## Chapter 8

- **[8-0](assignments/Ch8/8-0/)** - A time converter that converts between hours and days using a converter class
- **[8-00](assignments/Ch8/8-00/)** - Generates a formatted table displaying the dimensions, perimeters, and areas of rectangles
- **[8-1](assignments/Ch8/8-1/)** - Approximates square roots using an iterative method
- **[8-4](assignments/Ch8/8-4/)** - Generates a monthly credit repayment schedule showing balances, interest, and payments.
## Chapter 10
- **[10-1](assignments/Ch10/10-1/)** - Organizes user provided integers into separate arrays containing even, odd, and negative numbers
- **[10-2](assignments/Ch10/10-2/)** - Calculates the average of a set of numbers and identifies the values greater than that average
- **[10-3](assignments/Ch10/10-3/)** - Finds the mode of a set of integers using arrays and frequency counting
- **[10-4](assignments/Ch10/10-4/)** - Expands on the previous assignment by calculating both the mode and median
- **[10-5](assignments/Ch10/10-5/)** - Further expands on the previous assignments by allowing the calculator to identify multiple modes and display a frequency distribution
